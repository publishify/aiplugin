# F1 roadmap

Founder-approved first implementation: server, plugin core and Fiction desk, Claude first.

1. Worker/OAuth skeleton, Google sign-in, account/identity/licence/session records and `whoami` tests.
2. Microsoft, Apple and email-code sign-in, including safe identity/licence linking and Apple private-relay handling.
3. Desk catalogue and form with window, form and conversation fallbacks; licence-aware choices.
4. Board session flow: start, next task, finish and status; allowance deducted once.
5. Versioned Editor, Continuity Auditor and Reader Panel role cards; advice without automatic rewriting.
6. Python host-side scripts and parity checks against the previous TypeScript logic.
7. Product plugin core and Fiction skill. Separate production packaging from `spike/`.
8. A shared report template with the Fiction view; render/open and download inside the AI environment.
9. The Fiction evaluation set in Claude, with recorded quality results and observed usage.
10. Production readiness, licence guide, final privacy/terms and an explicitly approved endpoint cutover.

Development uses a temporary address. Changing the production MCP endpoint is a separate release action, not a consequence of writing these documents.

## Beyond F1

Books; publication preparation; students; academic; business/institutions. Each desk needs an explicit input contract, role assignments, scripts, rules, evidence requirements and evaluation set. Roadmap entries are not offered capabilities.

Review modes and limited one-off/monthly/yearly licences are planned. Exact prices, word budgets and re-review allowances are unresolved. Three preliminary reviews per month are a planned free allowance, not an active checkout promise.
