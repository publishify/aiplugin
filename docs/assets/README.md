# Editorial board artwork

The PNG files in this folder are the English and Turkish versions of the illustrative board graphic used on https://publishify.app.

- PNG: 1360 × 1160, for predictable rendering in GitHub READMEs.
- The scalable SVG originals live on the website (`/img/masthead-night-press-en.svg`, `-tr.svg`); the plugin directory accepts no SVG except an icon.
- Caption: illustrative review office and narrative map, not a real manuscript report, quality metric or current completion indicator.

The Seven Stages narrative lens is attributed to Ali Osman Akçaoğlu. Keep existing branding and do not infer reuse rights from repository visibility.
