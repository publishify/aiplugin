# Fiction desk

The first F1 desk targets novels and short stories, in Claude first.

| Assignment | Input | Expected output |
| --- | --- | --- |
| Editor | A chapter plus necessary context | Problems and strengths, source location, short quotation, reasoning and useful questions |
| Continuity Auditor | Fact ledger, script flags and the relevant passages | Candidate inconsistency assessment; two locations for a contradiction claim |
| Reader Panel | Defined reading scope and perspective | Simulated reactions about curiosity, clarity, emotion and expectations |

## A useful finding

A finding should distinguish the observed passage from its interpretation. Its source location and quotation must be verifiable. Contradictions require both sides; a flag from a name or death-tracking script is only a candidate.

Flashbacks, dreams, unreliable narration, time changes and deliberate stylistic choices can explain apparent inconsistencies. Finding the words is not the same as proving the diagnosis.

## Writer's authority

The desk produces feedback and editorial questions. It does not automatically rewrite the manuscript, promise publication or guarantee that every error will be found.

## Narrative lens

Ali Osman Akçaoğlu's Wayfarer's Seven Stages places the wayfarer's inner need at the centre: Call, Guide, Threshold, Trial, Awakening, Reward and Return. It is optional interpretive scaffolding, not a universal scoring formula.

[English guide](https://publishify.app/blog/the-wayfarers-seven-stages/) · [Türkçe rehber](https://publishify.app/tr/blog/yolcunun-yedi-merhalesi/)

## Report goal

Bring prioritised findings, strengths, source references and the narrative view together in one dashboard, with a downloadable report generated in the AI environment. UI examples in this repository are illustrative; the real report template is part of implementation.
