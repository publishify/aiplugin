# Contributing

The repository is at the transition from a completed technical spike to F1 implementation. Documentation and narrowly scoped fixes are welcome; do not present planned functionality as shipped.

## Before changing a workflow

1. Check whether the file belongs to the retired spike or the actual product.
2. State the affected host and its version/environment: web, desktop, desktop Code tab or terminal.
3. Provide a small synthetic fixture, expected output and reproducible steps.
4. Check failure, cancellation and approval paths as well as the successful case.
5. Keep host-side manuscript checks separate from service-side licence/session rules.

## Documentation and visuals

English introduction: `README.md`. Turkish introduction: `README.tr.md`. Public technical notes: `docs/`. Board artwork: local PNG and SVG variants in `docs/assets/`, copied from the website. Keep captions identifying these as illustrative.

Keep the approved logo, vertical book/P proportions and green palette. Do not replace the artwork with screenshots of a user's manuscript. Attribute the Seven Stages approach to Ali Osman Akçaoğlu.

## Safety and licensing

Use synthetic text in issues. Do not post manuscripts, personal data, credentials or private MCP source. Public visibility is not a software licence; a reuse policy still needs an explicit licence decision. This document does not grant a brand or artwork licence.
