# Verification record and limits

Founder-recorded trials: 15 November 2026. This document summarises the supplied trial record; it does not claim a fresh independent reproduction.

## Observed

- Claude web: connection/sign-in, form, window and button, state-changing tool and scripts on an attached sample. Cloud upload-path visual confirmation remains open.
- Claude desktop: plugin installation, connection, form/window/button and scripts. The first desktop file test used computer access on the Mac; it was not an attached-cloud-file proof.
- Claude Code desktop Code tab: command, sign-in, tools and scripts. Elicitation was not displayed. A window appeared, but its tool button failed with `IPC not available for MCP tool call`. Terminal Claude Code needs separate validation.
- ChatGPT Plus: custom OAuth MCP, form, window/button, state-changing tool, and Python script supplied as an attachment. Packaged-skill execution was not tested.
- Codex CLI 0.169.0: the Claude test package installed unchanged; OAuth, scripts and user-approved state changes worked. No inline window or form. Unattended execution could not provide required approval.

The small word-count sample yielded 10 words and 47 characters; the sample's byte count differs for UTF-8 text. Submitted server results contained counts, not manuscript content.

## Not established

A complete novel review; Fiction quality acceptance; universal host/plan availability; native separate-context subagents; every report download path; resumption across conversations; partial re-review correctness; final pricing; production deletion/retention timings.

Cursor and Gemini CLI were not tested. ChatGPT Free/Pro, the ChatGPT packaged-skill path and account-level installation for web/mobile remain untested in this record.

## Product acceptance gate

A writer installs the real plugin in Claude, signs in, selects Fiction, attaches a manuscript in the AI host and receives a dashboard populated with source-verified findings. The Fiction evaluation set, including Aşk-ı Memnu, must run in Claude and record results plus observed AI usage. A successful transport spike does not satisfy this gate.
